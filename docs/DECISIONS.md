# Журнал решений

Решения, принятые при подключении стандартов. **Перед подключением нового стандарта прочитай журнал целиком и действуй
по прецедентам.** Новое решение (область, спорный разбор, исправление распознавания, изменение ограничения схемы)
дописывай в конец своего раздела в том же PR: дата, стандарт, вопрос, решение, где закреплено.

Источники первого заполнения: `docs/RULES.md` (раздел 8), история в шапке `config/registry_schema.yaml`,
docstring `tests/test_regression.py`, шапки и комментарии конфигов, комментарии `config/merge.yaml`.
Истории коммитов у репозитория нет (один merge-коммит), раздела README «Принятые решения» в README нет.
Дата «дата не зафиксирована» — в источниках её нет.

«Закреплено» — где решение действует: ключ конфига, правило схемы, тест, раздел RULES.md.

## Как дописывать

1. Строка в таблицу своего стандарта (или в «Общие решения», если решение для всех): дата, вопрос, решение, где закреплено.
2. Решение, которого нет в журнале и которое не выводится из прецедентов, — вопрос владельцу (критерий остановки в `prompts/add_gost.md`).
3. Область нового стандарта предлагает агент: в журнал — раздел → значение, исключения по пунктам и основание.
